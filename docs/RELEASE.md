# Release scope

Version 0.3.0 contains selected statistical model implementations for the Q1, Q2, Q3 local and full-range, and supplementary S18 analyses, together with synthetic verification tests.

The software requires separately prepared eligible study inputs. It does not include participant-level data, cohort extraction procedures, restricted research outputs, or the complete historical analysis pipeline. Passing the included tests does not establish numerical identity with estimates reported in the manuscript.

The software is MIT-licensed. Consult the repository visibility and tagged releases on GitHub for current distribution status.
